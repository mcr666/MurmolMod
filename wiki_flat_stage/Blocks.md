# 方块 (Blocks)

> 全部方块整合页。注册 id 默认在 `murmol` 命名空间下。

## 核心交互方块

| 方块 | id | 说明 |
|---|---|---|
| 唤灵台 | `spirit_table` | 变形系统核心。4 槽位摆祭品，手持摩摩尔之魂右键变形；手持魂之瓶右键收取灵魂。配方：磨制深板岩+工作台+幻星锭+黑曜石 |
| 磐座 | `banza` | 狛犬专属。右键使狛犬立即石化并缓慢回血；可堆叠 1~4 层（每层 4/16 高）。配方：横排两苔石 |
| 两仪 | `two_principles` | 太极薄板方块，右键打开形态管理 GUI（3 级权限可编辑），管理各形态启用状态。配方：四白四黑混凝土太极形+摩摩尔之魂 |
| 照妖镜（方块） | `truth_mirror` | 1px 薄板，照妖镜物品潜行右键贴六面放置；右键镜面给 10 秒显形 |

## 机关 / 陷阱

| 方块 | id | 说明 |
|---|---|---|
| 囚笼 | `cage` | 红石激活时踩到笼顶的实体被传送进笼内禁锢；断电弹出、破坏释放；被困者只能挖脚下自救。硬度同钻石块。配方：4 铁栏杆+2 铁块+2 黑曜石+摩摩尔之魂 |
| 诅咒石头 | `cursed_stone` | 玩家踩上或挖掘触发石化；挖掘碎裂并掉落。配方：`cursed_stone.json` |
