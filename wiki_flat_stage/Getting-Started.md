# 上手指南

MurmolMod 的核心循环：**寻找神兽踪迹 → 集齐祭品 → 变形 → 探索星幻大地、对抗强敌 → 两仪管理形态开关**。

## 第一步：找到《峰洋经》与秘典
- **古代知识残页**（`ancient_knowledge_scrap`）：藏于幻星废墟与猫哭冢宝箱，右键解锁手册条目（不消耗），也是形态之魂合成材料。
- **幻星秘典**（`the_astral_tome`）：右键打开帕秋莉手册《星幻秘典》，内含全部形态与机制双语指引。

## 第二步：获取摩摩尔之魂
**摩摩尔之魂**（`murmol_soul`）是变形核心媒介，也是合成各形态之魂的基础。

## 第三步：变身
- **形态之魂**：手持对应形态之魂右键直接变身。
- **唤灵台**：摆好祭品，手持摩摩尔之魂右键，匹配成功即变形。
- **返归人类**：照妖镜举起 3 秒，或配方（水桶 + 不死图腾 + 绿宝石 + 任意船）。

详见 [Transformation Items](Transformation-Items) 与 [Forms](Forms)。

## 第四步：探索与对抗
- 探索**星幻瘟疫群系**，采集幻星木/矿石，制作幻星工具与盔甲（[Blocks](Blocks)）。
- 对抗**奥尔法**、**贪食者史莱姆**（[Entities](Entities)）。
- 利用磐座（狛犬）、照妖镜（显形）、囚笼等机制（[Systems](Systems)）。

## 进阶玩法
- **两仪**：管理各形态启用状态，禁用形态无法变形。
- **照妖镜/显形**：揭开真身。
- **麻雀**：找到摩摩尔 NPC 或前往麻雀屋，进行四人立直麻雀对局（[Mahjong Items](Mahjong-Items)）。
