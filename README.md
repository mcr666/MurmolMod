# Murmol

1.21 NeoForge 模组。以"星幻瘟疫"后的末日世界为背景，加入形态变形、唤灵台、星象仪 wiki、立直麻雀等内容。

## 信息

- **MC 版本**：1.21.x
- **加载器**：NeoForge 21.1.x
- **Java**：21
- **版本**：2.2.4
- **作者**：Maocry

## 内容

- **形态系统**：8 种神话形态（落瓣春花、乘黄、苔叶兽、月蛾、狛犬、文鳐、狰、黯忿），各有独特属性、能力与传记
- **唤灵台**：摆放祭品 + 摩摩尔之魂完成变形
- **星象仪**：内置 wiki 界面，记载所有物品与形态知识
- **星幻瘟疫**：主线剧情背景设定
- **立直麻雀**：末日麻将机，支持牌谱回放
- **药水与附魔**：石化、显形、星幻感染、人类杀手、薛定谔等

## 依赖

- NeoForge（必需）
- Patchouli（可选，不装也能正常运行）
