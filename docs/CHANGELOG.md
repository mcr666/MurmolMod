# MurmolMod 更新记录

## 2.1.2 (2026-09-25)

### 新增
- **新形态：狛犬（Komainu）**：使用乘黄同款默认动画；静止 5 秒进入"石像"状态（抗性提升 I、贴图变为原版石头、锁定潜行动画、2 格外怪物无法察觉、进出伴随石头破坏粒子），移动解除；站立在磐座上右键立即石化，石像期间缓慢回血
- **磐座 (Banza Pedestal)**：4/16 高苔石基座方块，狛犬石像的触发与回血载体
- **芒果丛**：类似甜浆果丛的四阶段灌木，芒果种植，成熟采收
- **量子态附魔**：佩戴者变形时护甲不再脱落；获取途径：图书管理员 4 级交易（12 绿宝石）、模组两个结构宝箱 5% 概率
- **月蛾环境机制**：露天白天 -0.05 移速 / -4 生命，夜晚 +0.05 / +4，黑暗处无增减；白天可睡觉
- **月蛾可穿胸甲**（胸甲槽不参与变形掉落）
- **乘黄 +2 护甲值**
- **月蛾默认显示第一人称手臂**（其余形态保持隐藏）
- **配置项**：`renderBiomeParticles`（模组群系环境粒子渲染开关，默认开，已汉化）；现有选项归入"客户端"分组

### 修复
- 月蛾翅膀采样取模修复（wings_idle / wings_flying 超过动画长度后僵住）
- 月蛾按住空格键即播放 wings_flying（无需等离地）
- 月蛾恢复原版碰撞箱与眼高
- 幻星秘典去除发光效果
- 手册"传颂之物"页改用 patchouli:crafting，修复 "Could not find entry" 报错；四形态中英文条目统一为四页格式
- 环境粒子 Mixin 重写（拦截 AmbientParticleSettings.canSpawn，避开 ClientLevel）

### 更改
- 主菜单配置合并：`modifyTitleScreen` 覆盖全景背景 + 按钮样式 + 主菜单音乐，默认关闭
- 芒果丛贴图本地化（textures/block/mango_bush_stage0~3.png）
- 月蛾手册同步昼夜增减益说明

## 2.1.0 (2026-09-18)

### 新增
- **唤灵台 (Spirit Table)**：新方块，4 个物品槽位，主手持物右键放入、空手或潜行右键依次取下，物品 2×2 平放展示于台面；手持幻星之魂右键进行无序配方检测，匹配成功消耗材料变形。可用磨制深板岩/幻星锭/工作台/黑曜石合成。模组菜单中的配置界面可调
- **Mod 配置选项**（客户端，即时生效，已汉化）：`modifyTitleScreen`（标题界面按钮样式与主菜单音乐，默认开）、`showHiddenFeralArm`（强制显示被形态定义隐藏的第一人称手臂，默认关）
- **不死图腾新用途**：变形状态下手持不死图腾右键，获得对应形态的灵魂物品（消耗图腾，40 tick 冷却）
- **Patchouli 手册联动**（可选前置）：幻星秘典右键打开星幻秘典手册（中英双语，2 栏目 4 条目），未安装 Patchouli 时正常游玩
- **JEI 形态配方**：查看幻星秘典或唤灵台可查看三种形态的变形配方与重归人类配方，并标注两种变形途径

### 修复
- 修复与 Patchouli 同时安装时的崩溃（移除遗留的 `astral_cruse` 命名空间音效类，GitHub issue #1）
- 修复 Tectonic 等地形 mod 下星幻感染群系无法生成/过小的问题（重写气候参数点，扩大生成范围）

### 更改
- 形态标识由数字改为字符串（旧存档自动迁移）
- 幻星矿生成重写：概率与远古残骸类似，深埋于主世界 Y -64~-24，不可露天发现，可替换石头/深板岩/幻星石头
- 唤灵台与幻星秘典的配方检测改为无序比对
- 星幻感染群系现在会生成原版怪物；群系表面与气候判定优化
- 删除 astral_tame 原本绑定的 GUI 及音效，物品改为幻星秘典手册
