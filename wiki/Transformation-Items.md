# 变形用物品 (Transformation Items)

> 变形系统的核心物品整合页。注册 id 在 `murmol` 命名空间下。

## 核心媒介

| 物品 | id | 说明 |
|---|---|---|
| 摩摩尔之魂 | `murmol_soul` | 变形钥匙：唤灵台上摆好祭品后手持右键触发变形；也是各形态之魂的合成基础 |
| 魂之瓶 | `soul_bottle` | 唤灵台上手持右键收取对应形态的灵魂物品 |
| 古代知识残页 | `ancient_knowledge_scrap` | 右键解读解锁手册条目（不消耗），也是形态之魂合成材料；藏于幻星废墟/猫哭冢宝箱 |
| 幻星秘典 | `the_astral_tome` | 帕秋莉手册《星幻秘典》入口（双语），需 Patchouli 前置 |
| 照妖镜 | `truth_mirror` | 举起 3 秒变回人类并消耗自身；潜行右键可贴方块六面放置成照妖镜方块（显形）。配方见源码 |

## 形态之魂 (Soul Items)

手持右键直接变身为对应形态。通用合成：**古代知识残页 + 摩摩尔之魂 + 对应祭品**。动态贴图 4 帧。

| 物品 | id | 对应形态 | 祭品要点 |
|---|---|---|---|
| 春花之魂 | `luohong_soul` | 落瓣春花 | 花相关 |
| 乘黄之魂 | `chen_huang_soul` | 乘黄 | 见形态类 |
| 苔叶之魂 | `moss_beast_soul` | 苔叶兽 | 见形态类 |
| 月蛾之魂 | `silkmoth_soul` | 月蛾 | 见形态类 |
| 狛犬之魂 | `komainu_soul` | 狛犬 | 石头/樱花树苗/骨头/钻石 |
| 文鳐之魂 | `wenyao_soul` | 文鳐 | 任意鱼(fishes)/幻翼膜/水草/水桶 |
| 狰之魂 | `ferocious_soul` | 狰 | 幻翼膜/烈焰粉/下界疣/兔子皮 |

## 获取途径汇总
1. **唤灵台 + 魂之瓶**收取。
2. **合成**（残页 + 摩摩尔之魂 + 祭品）。
3. 变形状态手持**不死图腾**右键，获得当前形态灵魂物品（消耗图腾，40 tick 冷却）。

## 使用注意
- 对应形态被**两仪**禁用时，使用灵魂物品会失败且不消耗。
- **显形**药效中不可用。
- 各形态机制详见 [Forms](Forms)。
