# 形态 (Forms)

> 全部可变形形态整合页。形态注册于 `FeralForms`，id 即 `/murmol tf <id>` 参数。变形材料与机制详见各条目。

## 环境属性修饰符

形态按环境自动增减属性，修饰符 id：
- `murmol:tf`（基础）· `tf_cave` / `tf_surface`（苔叶兽洞穴/地面）
- `tf_silkmoth_day` / `tf_silkmoth_night`（月蛾昼夜）
- `tf_wenyao_water` / `tf_wenyao_land`（文鳐水陆）

## 通用机制
- **变形途径**：形态之魂右键 / 唤灵台摆放祭品+摩摩尔之魂右键 / 返归人类配方 / 照妖镜。
- **变身瞬间**：附加 失明 + 创造冲击 + 缓慢 各 3 秒。
- **骑乘**：骑乘载具时动画统一为潜行待机（坐姿）。
- **两仪**：被禁用的形态无法通过信物变形，指令变形绕过。
- **显形**：显形药效中灵魂物品与照妖镜不可用。
